# Learning Mode v1

El modo de aprendizaje acelerado opera exclusivamente con PaperBroker y dinero simulado.

- Capital inicial: 5,000 MXN.
- Tamaño base por operación: 50 MXN.
- Universo inicial ampliado: BTC, ETH, SOL, XRP, USDT, DOGE, ADA, AVAX, LINK y ARB.
- Los libros no disponibles se aíslan y no detienen el resto del ciclo.
- El Runtime contabiliza observaciones y decisiones para mostrar progreso visible.
- LIVE_TRADING permanece desactivado.

Este modo acelera la recolección de observaciones; no reemplaza el histórico real ni garantiza rentabilidad.
